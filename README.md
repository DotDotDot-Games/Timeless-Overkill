# Timeless-Overkill

Timeless Overkill is a game set as the world is about to end; amidst the resulting chaos, you decide to spend your final two minutes of life killing everyone you come across!

## How to play

- WASD: Move
- Mouse Left Click: Shoot
- Space: Dash
- Get closer to things that appear on the map: Take it
- TAB: Pause
